# DEEP SEA SCROLL — 深海を潜る

スクロールすると海の底まで潜っていくだけのページ。
0m からチャレンジャー深淵 10,911m まで。

## 遊び方

- **下にスクロール** = 潜航。深度が増え、周りが暗くなり、文字が発光しはじめる
- **浅瀬** — ほぼ光らない普通の文字
- **深海** — 生物発光のような青白い光を文字が放つ
- **思い切り上にスクロール** = 急浮上。泡が湧くので注意
- 右の縦書き HUD が現在深度と深度帯を表示

## 仕組み

- フレームワークなし。HTML 1枚 + CSS + JS（バニラ）
- スクロール位置 → セクションの `data-depth` から深度を線形補間
- 深度 → 背景色を `COLOR_STOPS` で補間、`body.style.backgroundColor` を直接更新
- 文字の発光は CSS 変数 `--glow` / `--glow-hue` を JS が更新、`text-shadow` の `calc()` が光量を計算
- パーティクルは Canvas 2D。深度が深いほど粒が増える（14 → 110）
- 泡は CSS アニメーションの DOM 追加
